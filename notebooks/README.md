# Notebooks

This directory is reserved for reproducible Jupyter notebooks.

Suggested notebooks:

1. `01_exploratory_analysis.ipynb` — inspect, clean, and visualize the data.
2. `02_country_comparison.ipynb` — compare selected indices and pandemic indicators.
3. `03_model_training.ipynb` — train and evaluate forecasting baselines.

Keep notebooks focused, explain each transformation, and record the dataset version used for every result.

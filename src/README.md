# Source code

Reusable Python modules can be added here as the project becomes reproducible.

Suggested modules:

- `preprocess.py` — data validation and cleaning.
- `features.py` — feature construction.
- `visualize.py` — charts and reporting plots.
- `models.py` — baseline and machine-learning models.
- `evaluate.py` — MAE, RMSE, and directional-accuracy calculations.

Keep exploratory work in `notebooks/` and reusable logic in `src/`.
